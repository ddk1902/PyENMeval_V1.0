# Examples for PyENMeval

This folder contains example scripts demonstrating the use of the `ENMevaluate` class from the `pyenmeval` library. The examples show how to run k-fold, jackknife, and block validation, and how to generate raster predictions.

---

## Files

- `example_run.py` : Main example script. Runs the complete workflow with simulated presence data and a simulated environmental raster.
- `env_raster.tif` : Simulated environmental raster created by the example script.
- `prediction_raster.tif` : Raster prediction generated by `ENMevaluate`.

---
